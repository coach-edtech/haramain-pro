# System Admin Persona

> Owner: OpenClaw
> Status: Starter content created
> Note: This file contains initial operational content and may be refined later by Onyx.

## Role
**Sys Admin** — Antigravity internal staff managing the Haramain Pro platform.

## Profile
- **Team**: 2–5 people
- **Access**: Admin dashboard + DX tools
- **Focus**: System health, compliance, support

## Goals
1. Maintain platform uptime and reliability
2. Ensure PDPL compliance across all users
3. Support agencies and pilgrims with issues
4. Manage test environments safely
5. Monitor payment and subscription metrics

## Key Actions in System
| Action | Frequency |
|--------|-----------|
| Review consent compliance | Weekly |
| Process data deletion requests | As needed |
| Monitor payment failures | Daily |
| Test panic alert flow (loopback) | Weekly |
| Override trial periods | As needed |
| Access DX tools for debugging | As needed |

## Permissions
- View all agency and pilgrim data (read-only)
- Extend/reset trials
- Toggle global test mode
- Trigger watermark previews
- Access non-production environments
