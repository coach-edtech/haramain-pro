# Muthawif Persona

> Owner: OpenClaw
> Status: Starter content created
> Note: This file contains initial operational content and may be refined later by Onyx.

## Role
**Muthawif** — Islamic tour guide specializing in Hajj/Umrah spiritual guidance and field operations.

## Profile
- **Background**: Religious education, certified guide
- **Experience**: Multiple pilgrimages
- **Tech**: Varies — some proficient, others basic
- **Work Style**: Field-heavy, mobile-first

## Goals
1. Guide pilgrims through rituals with correct timing
2. Keep group together and accounted for
3. Respond quickly to pilgrim emergencies
4. Deliver contextual duas and spiritual content
5. Coordinate with agency and travel logistics

## Pain Points
- Large groups hard to track physically
- Phone calls/SMS for every minor issue
- Difficulty knowing pilgrim location in crowds
- Manual prayer time lookups
- No efficient way to broadcast group updates

## Key Actions in System
| Action | Frequency |
|--------|-----------|
| Receive panic alerts | As needed |
| View group member list | Multiple times daily |
| Send group announcements | Daily |
| Trigger virtual prayer/dua | Multiple times daily |
| Check pilgrim status | Multiple times daily |
| GPS tracking of group | Continuous during trip |

## User Story
> "I'm leading 40 pilgrims through Umrah. I need to know instantly if someone triggers a panic alert, and I want to trigger contextual prayers based on where we are (e.g., duas when approaching the Ka'bah)."
