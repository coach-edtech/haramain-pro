# Pilgrim Persona

> Owner: OpenClaw
> Status: Starter content created
> Note: This file contains initial operational content and may be refined later by Onyx.

## Role
**Jamaah** — Individual Muslim pilgrim performing Hajj or Umrah.

## Profile
- **Age**: 25–65 (wide range)
- **Tech Savvy**: Moderate — uses WhatsApp, Instagram, but not power users
- **Language**: Indonesian (primary)
- **Context**: First-time or repeat pilgrim, may be anxious about logistics and safety

## Goals
1. Complete pilgrimage safely and spiritually
2. Stay connected with group (rombongan) members
3. Document spiritual journey (jejak ibadah)
4. Access offline maps and navigation in Mecca/Medina
5. Receive timely spiritual guidance (prayer times, duas)

## Pain Points
- Unreliable WiFi/cellular in Saudi Arabia
- Difficulty finding exact prayer locations
- Anxiety about getting separated from group
- Language barriers
- Overwhelming scale of Hajj rituals

## Key Actions in System
| Action | Frequency |
|--------|-----------|
| Joinrombongan via PIN | Once per trip |
| Buy Safety Pass | Once per lifetime |
| Trigger Panic Alert | Rare (emergency only) |
| Log Jejak Ibadah | Multiple times daily |
| View Offline Maps | Multiple times daily |
| Receive Prayers/Notification | Multiple times daily |

## User Story
> "I'm a first-time pilgrim. I want to feel safe knowing I can call for help if I get lost, track my spiritual activities, and navigate offline without burning through data."
