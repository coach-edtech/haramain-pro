# Travel Agency Persona

> Owner: OpenClaw
> Status: Starter content created
> Note: This file contains initial operational content and may be refined later by Onyx.

## Role
**Travel Agency (PPIU)** — Licensed Umrah/Hajj travel company managing pilgrim groups.

## Profile
- **Type**: Small to mid-sized Indonesian travel agency
- **Staff**: 3–20 employees
- **Tech**: Moderate — uses accounting software, WhatsApp Business, email
- **Volume**: 50–500 pilgrims per season

## Goals
1. Manage multiple groups (rombongan) efficiently
2. Ensure pilgrim safety during trip
3. Differentiate service with premium features
4. Streamline passenger data management
5. Reduce manual coordination effort

## Pain Points
- Managing large groups via WhatsApp broadcasts (chaotic)
- No visibility into individual pilgrim locations
- Difficulty confirming payment and consent status
- Manual passenger list updates
- Coordinating with multiple muthawif

## Key Actions in System
| Action | Frequency |
|--------|-----------|
| Register agency (PPIU onboarding) | Once |
| Purchase volume license | Per season |
| Create rombongan | Per group |
| Invite Jamaah | Per passenger |
| Monitor group status | Daily during trip |
| Assign muthawif to kelompok | Per group |

## User Story
> "We run Hajj groups twice a year with 100+ pilgrims. I want a dashboard to see all my groups, track payments, and make sure every pilgrim has consented and can access safety features."
