## What It Does
Core B2B feature: travel agencies create and manage pilgrimage groups, invite Jamaah via PIN, assign muthawif.

## Key Entities
- **Rombongan**: Group entity with trip dates
- **Members**: Jamaah in the group
- **Muthawif**: Guide assigned to group

## Core Flows
- Create group → generate PIN
- Jamaah join via PIN
- Muthawif assignment
- Group expiry at trip_end_at
- B2B bypass invite (direct assignment)
