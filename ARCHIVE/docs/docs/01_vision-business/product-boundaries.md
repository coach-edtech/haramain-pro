# Product Boundaries

> Owner: OpenClaw
> Status: Starter content created
> Note: This file contains initial operational content and may be refined later by Onyx.

## Purpose
Defines what Haramain Pro is — and is not. Clear scope boundaries for MVP and future releases.

## In Scope (MVP)

### B2C (Jamaah/Pilgrim)
- Safety pass subscription (Rp 120,000 lifetime)
- 7-day free trial
- Panic alert with fallback layering
- Offline maps (Mapbox, max 300MB)
- Virtual muthawif (geofence-triggered prayers/duas)
- Jejak ibadah (spiritual activity logging with watermarks)
- Group join via numeric PIN

### B2B (Travel Agencies + Muthawif)
- Agency onboarding (PPIU registration)
- Rombongan group management
- B2B volume licensing (Rp 90,000/pax base)
- Guest list management
- Group invite (B2B bypass mode)

### Compliance
- PDPL consent capture (location, media, push, marketing)
- Marketing consent separate from core services
- Data deletion and withdrawal flows

## Out of Scope (MVP)
- Passport or biometric data collection
- Flight/hotel booking
- Visa processing
- Social features beyond group coordination
- AI chatbot for spiritual advice

## Future Phases
- B2B admin dashboard
- Advanced analytics for agencies
- Multi-language support
- Expanded offline regions
