## Purpose
Group (rombongan) data model — core organizational unit.

## Tables

#### `public.rombongans`
| Column | Type | Description |
|--------|------|-------------|
| `id` | UUID | PK |
| `agency_id` | UUID | FK → agencies |
| `name` | TEXT | Group name |
| `trip_start_at` | TIMESTAMPTZ | Trip start date |
| `trip_end_at` | TIMESTAMPTZ | Trip end date |
| `status` | ENUM | 'planning', 'active', 'completed', 'cancelled' |
| `pin_code` | TEXT | 6-digit numeric PIN |
| `created_at` | TIMESTAMPTZ | |
| `created_by` | UUID | FK → profiles |

#### `public.rombongan_members`
| Column | Type | Description |
|--------|------|-------------|
| `id` | UUID | PK |
| `rombongan_id` | UUID | FK → rombongans |
| `user_id` | UUID | FK → profiles |
| `role` | ENUM | 'jamaah', 'muthawif', 'lead' |
| `joined_at` | TIMESTAMPTZ | |
| `left_at` | TIMESTAMPTZ | Nullable |

## Lifecycle

```
planning ──trip_start──▶ active ──trip_end──▶ completed
    │                       │
    │                       └── OR ──▶ cancelled (if needed)
    │
    └── PIN/generation happens here
```

## PIN Logic
- 6-digit numeric, generated on creation
- Unique per agency (scope to agency_id)
- Can be regenerated by agency admin
