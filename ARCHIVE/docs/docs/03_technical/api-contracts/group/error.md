## Purpose
Error codes and responses for group management endpoints.

## Error Codes

| Code | HTTP Status | Meaning | Handling |
|------|-------------|---------|----------|
| `INVALID_GROUP_PIN` | 404 | PIN not found or expired | Check with agency |
| `GROUP_EXPIRED` | 403 | Trip already ended | Cannot join past trips |
| `GROUP_FULL` | 403 | Maximum members reached | Contact agency |
| `NOT_IN_GROUP` | 404 | User not a member of this group | Join group first |
| `NOT_AUTHORIZED` | 403 | Not permitted (not agency/muthawif) | Check role |
| `TRIP_START_VALIDATION` | 400 | Cannot create group in the past | Use future dates |
| `AUTH_REQUIRED` | 401 | Not authenticated | Authenticate first |

## Notes on 6-digit Numeric PIN
- Format: exactly 6 digits, e.g., "482193"
- Generated server-side (not client-provided)
- Unique per agency scope
- Can be regenerated by agency admin
- Expires when group status → completed

## Error Response Shape
```json
{
  "error": {
    "code": "INVALID_GROUP_PIN",
    "message": "The group PIN you entered is incorrect or expired",
    "action": "contact_agency"
  }
}
```
