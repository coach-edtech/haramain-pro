# Milestone 4 — User Journeys

> Owner: OpenClaw
> Status: Starter content created
> Note: This file contains initial operational content and may be refined later by Onyx.

## Objective
Complete end-to-end user journeys for B2C pilgrims, B2B agencies, and Muthawif.

## Scope
- B2C pilgrim journey (signup → trial → join group → trip → alumni)
- B2B agency journey (onboard → purchase → manage → reports)
- Muthawif field ops journey (assignment → monitoring → emergency → handover)
- Virtual Muthawif (geofence-triggered prayers/duas)
- Alumni broadcast (marketing consent + FCM)

## Deliverables
- [ ] B2C journey: all screens and flows
- [ ] B2B dashboard: group management, passenger list
- [ ] Muthawif app: group monitoring, panic response
- [ ] Virtual Muthawif: geofence + content delivery
- [ ] Alumni broadcast: audience selection + send

## Dependencies
- Milestones 0–3 complete
- All features integrated

## Success Criteria
- Pilgrim can complete full journey (signup → trip end)
- Agency can onboard, purchase license, manage groups
- Muthawif can monitor group and respond to panic
- Geofence triggers contextual content
- Alumni can receive broadcasts (with consent)
