# Release Notes - Haramain Pro v0.1.0-beta

**Version:** 0.1.0-beta
**Date:** 2026-05-13
**Type:** Beta Release

---

## Overview

v0.1.0-beta is the first public beta release of Haramain Pro - an Umrah companion app focused on safety and security for Jamaah traveling to Saudi Arabia.

## Features

### Core Features

#### 🔐 Authentication
- Email/password registration and login
- Google OAuth integration
- Apple Sign-In integration
- Role-based access (Admin, Muthawif, Jamaah)

#### 🚨 Panic Button (Critical)
- One-tap emergency alert
- 5-second countdown with cancel option
- GPS location auto-attached
- Dual notification to Muthawif AND Team Support
- Twilio SMS fallback for offline scenarios
- 5-minute rate limiting to prevent spam

#### 🗺️ Offline Maps
- OpenStreetMap tiles
- Download Makkah & Madinah regions for offline use
- Search places
- Route navigation
- Panic alert location display

#### 👥 Group Management
- Create group with QR code invitation
- Join group via QR code
- View group members
- Broadcast messaging

#### 💳 Payment
- Safety Pass: Rp 120,000 lifetime
- Independent: Rp 90,000
- Small: Rp 75,000/month (45 pax)
- Medium: Rp 60,000/month (90 pax)
- Midtrans integration ready

#### 🇸🇦 SDAIA NRC Registration
- Passport information capture
- Visa details
- Accommodation in Saudi
- Itinerary planning
- Image upload for documents
- Required for Saudi compliance

#### 📿 Virtual Muthawif
- AI-powered dua suggestions based on sacred zone
- Location-aware guidance

## Limitations (v0.1.0-beta)

1. **Payment** - Simulated, no real transactions
2. **FCM** - Requires google-services.json from Firebase Console
3. **Supabase** - Points to production project (haramain-prod-db)
4. **iOS** - Not tested in this release

## Installation

### Android
1. Transfer `app-release.apk` to device
2. Enable "Install from unknown sources"
3. Install and open

### Prerequisites
- Android 6.0+ (API 23)
- Google Play Services (for Maps)
- Location permission
- Notification permission
